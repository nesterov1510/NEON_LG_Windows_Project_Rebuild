# BeletFilm и Alem TV для рабочего стола Kali Linux

Готовые `.deb` лежат в [packages](packages). Это два независимых приложения для компьютера: NEON, телевизор, Developer Mode и Windows-инсталлер не нужны. Клиенты используют GTK 3, WebKitGTK 4.1 и GStreamer из репозитория дистрибутива. Архитектура пакетов — `all`: машинный код движка и кодеков устанавливает APT под архитектуру системы.

Из корня репозитория:

```sh
cd kali-desktop/packages
sudo apt update
sudo apt install ./beletfilm_1.0.1_all.deb ./alemtv_1.0.1_all.deb
```

Можно указать только один файл. Если пакеты скачаны отдельно, выполняйте команду `apt install` из каталога загрузки. Нужны графическая сессия Kali Rolling и возможность установить системные зависимости.

В меню **Мультимедиа** выберите **BeletFilm** или **Alem TV**; команды запуска — `beletfilm` и `alemtv` (без `sudo`). Работают мышь, стрелки, Enter и Esc. F11 переключает полноэкранный режим. Для просмотра нужен доступ к серверам соответствующего сервиса, а для платного контента — аккаунт/подписка. В Alem TV выберите портал своего оператора; некоторые порталы доступны только из его сети и используют HTTP.

Данные входа, MAC привязки и настройки сохраняются раздельно в `~/.local/share/beletfilm` и `~/.local/share/alemtv` (с учётом `XDG_DATA_HOME`). Удаление приложений не удаляет профиль пользователя:

```sh
sudo apt remove beletfilm alemtv
```

**Для разработчика:** `python3 kali-desktop/build.py` из клона пересобирает оба пакета через `dpkg-deb`. BeletFilm использует файлы клиента `belet_samsung_native`, Alem TV — HTML/CSS/JS из `alemtv_app.py`; ни одно приложение не загружает интерфейс из репозитория при запуске. После установки `kali-desktop/smoke.py` проверяет инициализацию упакованных страниц в WebKit (нужна графическая сессия или `xvfb-run`).
